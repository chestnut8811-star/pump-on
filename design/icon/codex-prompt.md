## 目的
iPhone 用 Web アプリ（PWA）「Pump On !」のアプリアイコンを、画像生成ツールで3案つくる。
このアプリは、心臓手術の人工心肺（cardiopulmonary bypass / heart-lung machine）を担当する日本の臨床工学技士（perfusionist）が、手術中に外科医・麻酔科医と交わす英会話を練習するための教育アプリ。名前の "Pump On" は人工心肺のポンプを回して体外循環を開始することに由来し、"On!" の前向きな勢いも表す。

## やること
1. 画像生成ツールで、下の共通条件を満たす3つの異なる案（A・B・C）を生成する。
2. 生成した PNG を次の名前でこのフォルダの candidates/ に保存する（生成先からコピーする）:
   - candidates/icon-a.png
   - candidates/icon-b.png
   - candidates/icon-c.png
3. それ以外のファイルは作成・変更しない（このフォルダの外には一切書かない）。
4. 最後に、各ファイルのパス・ピクセルサイズ・1〜2行の説明を報告する。

## 共通条件（アイコンの仕様）
- 正方形 1024x1024、フルブリード、背景は不透明（透過なし）。角は丸めない（iOS が自動で角丸マスクをかける）。
- 主要な要素は中央 80% の範囲に収める（Android の maskable アイコンでも切れないように）。
- 60px 程度に縮小しても形が読み取れる、太く単純な形。細い線や小さな装飾は使わない。
- スタイル: フラットでモダンなベクター調。影は使うとしても控えめな1段だけ。信頼感のある医療教育アプリらしさと、親しみやすさ・楽しさの両立。
- 配色（目安）: 深いネイビー #0B1F3A、パーフュージョン・ティール #12B5A6、動脈ライン赤 #F0435A、静脈ライン青 #3D8BFF、白。人工心肺回路の「送血＝赤、脱血＝青」の色分けをモチーフに使ってよい。
- 入れてはいけないもの: 文字・アルファベット・数字、リアルな血液、解剖学的な心臓、赤十字、注射器、写真調の表現、ごちゃついたグラデーション。

## 3案の方向性
- 案A: 中央に白い吹き出し（会話）。吹き出しの中に、ローラーポンプのポンプヘッド（円形のレースウェイと、中心を通る回転子の棒、その両端の2つのローラー）を単純化して描く。赤いチューブと青いチューブが吹き出しの下を回り込んで、ひとつのループ（体外循環回路）をつくる。背景はネイビーからティールへの斜めグラデーション。
- 案B: ローラーポンプのヘッドそのものを主役にし、回転子の棒と円の切れ目が電源ボタンの「オン」記号にも見えるようにする。円の一部に吹き出しのしっぽを付けて会話を表す。背景はティール単色または控えめなグラデーション。
- 案C: 赤い吹き出しと青い吹き出しが、回路のように互いに噛み合って輪をつくる（送血と脱血、話す側と聞く側）。つなぎ目に小さなポンプの回転子を置く。背景はネイビー。
