# 要件定義書: Pump On !（CPB英会話シミュレーター）

作成日: 2026-10-12

## 目的

心臓血管外科手術の人工心肺（CPB）業務に携わる日本の臨床工学技士が、外科医・麻酔科医・看護師と英語で交わす
会話を、手術の流れに沿って疑似体験しながら身につける。単語帳ではなく「聞いて分かる・状況で選べる・自分で言える・
流れの中で会話できる」ことを目標にする。中心的な価値は「人工心肺中の会話の疑似体験（CPB英会話シミュレーター）」。

## 利用者と利用環境

- 利用者: 心臓手術・人工心肺に携わる臨床工学技士（英会話は初心者〜中級者）。まずユーザー本人と部署の同僚。URL/QRで配れる形にする。
- 動作環境: iPhone の Safari と「ホーム画面に追加」した Web アプリ（PWA）。iPad・PC のブラウザでも崩れないこと。
- 配布形態: 静的サイト（HTTPS）。公開先は GitHub Pages を想定（公開の実施はユーザー確認後）。
- オフライン: 一度開けば、通信なしで全機能（音声読み上げを含む）が動く。

## 機能要件

### 必須（これがないと完成と言えない）

- [ ] **手術の流れに沿ったシーン構成**: 人工心肺前〜カニュレーション〜CPB開始〜ベント〜冷却〜大動脈遮断・心筋保護〜CPB中の管理〜復温〜空気抜き・遮断解除〜離脱〜プロタミン・脱血管抜去、＋トラブル対応。各シーンに日本語の状況解説を付ける。
- [ ] **フレーズ教材**: 各フレーズに、英語・日本語の意味・話者と相手・使う場面・典型的な返答・聞き取るべき単語と数値を持たせる。同じ意味の「簡単な表現」「自然な表現」「現場の短縮表現」を並べて違いが分かるようにする。
- [ ] **会話（ダイアログ）教材**: シーンごとに数往復の会話例。話者ごとに音声を変えて再生し、自分（臨床工学技士）の役を演じるロールプレイができる。
- [ ] **4種類のトレーニング**:
  - 聞く: 英語音声 → 意味を選ぶ、数値を聞き取る
  - 選ぶ: 状況（日本語）→ 適切な英語を選ぶ
  - 話す: お手本を聞いて自分で発話（シャドーイング・録音して聞き比べ）。音声認識が使える端末では自動判定も併用
  - 会話する: シミュレーター
- [ ] **CPB英会話シミュレーター**: 症例（架空）を選び、手術の進行に沿って相手の発話（音声）に応答していく。人工心肺のモニター風表示（流量・血圧・温度・ACT・遮断時間など）が進行に合わせて変わる。難易度（字幕あり〜音声のみ・時間制限あり）を選べる。終了後に振り返り（聞き逃した語・言えなかった表現）を出し、復習に回す。トラブル対応の症例を含む。
- [ ] **音声**: 英語の読み上げ（端末の音声合成）。話者ごとの声の割り当て、速度調整。
- [ ] **復習**: 間隔反復（忘れかけた頃に再出題）と、間違えた項目の復習。
- [ ] **進捗管理とゲーミフィケーション**: シーンごとの習熟度、連続学習日数、経験値とレベル、バッジ。データは端末内に保存し、書き出し・読み込みができる。
- [ ] **医学的正確性の明示**: 全教材に監修状態（AI下書き・臨床未監修 / 要確認 / 監修済み）を持たせ、施設差・地域差（米英など）・不確実な表現にはその旨の注記を表示する。根拠資料の一覧をアプリ内に置く。初回起動時と設定画面に「教育用であり施設プロトコルに従うこと」を示す。
- [ ] **PWA**: ホーム画面に追加でき、全画面表示・オフライン動作・iPhone のノッチ/ホームバー領域に対応する。
- [ ] **UI は日本語**（教材の英語はそのまま）。医療教育アプリらしい信頼感と、繰り返したくなる楽しさを両立する。

### あれば良い（今回のスコープから外してもよい）

- [ ] 数値の聞き取りを無限に練習できるミニゲーム（流量・圧・温度・ACT・時刻などの読み上げ）
- [ ] 手術室の環境音（ポンプ音・アラーム音）を重ねて聞き取る「本番モード」
- [ ] 用語集（略語・発音つき）
- [ ] 監修者向けの教材一覧（チェック用シート）の書き出し
- [ ] ダークモード
- [ ] 将来のネイティブ化（Capacitor）を妨げない構成

## 非機能要件

- 性能: iPhone で初回表示が数秒以内。画面遷移は即時。2回目以降はオフラインで起動。
- セキュリティ・個人情報: 外部送信なし（解析タグ・外部フォント・CDN を使わない）。学習記録は端末内のみ。患者情報は扱わない（症例はすべて架空）。
- アクセシビリティ: タップ領域 44pt 以上、十分なコントラスト、動きを減らす設定を尊重。
- 保守性: 教材は型付きのデータファイルに分離し、整合性を自動テストで検証する（ID重複、必須項目、注記・出典の参照切れ）。

## 前提・制約（技術選定を含む）

- 2026-10-12 ユーザー決定: iPhone 向けは **PWA（ホーム画面に追加）**。URL/QR で配れ、費用・審査が不要なため。ネイティブ化は将来 Capacitor で可能な構成にする。
- 2026-10-12 ユーザー決定: アプリ名は **「Pump On !」**、アイコンは **Codex の画像生成** で作る。
- 技術構成: Vite + React + TypeScript（ユーザーの既存教材 CIEDs問題集と同じ系統で保守しやすい）。PWA 化は vite-plugin-pwa。音声は Web Speech API（音声合成・認識）と MediaRecorder（録音）。
- 実行時に生成AIは使わない。教材（正解・解説・数値）は固定データとし、監修可能にする。
- 臨床内容（数値・手順・薬剤）は AI が創作しない。ガイドライン等で裏付け、裏付けのないものは「要確認」と表示する。会話中の数値は「例」であることを明示する。

## スコープ外（今回やらないこと）

- ネイティブ iOS アプリ化（Capacitor / SwiftUI）と App Store 配布
- アカウント・クラウド同期・ランキング
- 生成AIとの自由会話
- 実患者のデータ・実際の手術音声の収録

## 未確定事項

- 臨床監修者: 未定。教材は「AI下書き・臨床未監修」として扱い、監修の仕組み（状態表示とチェック用一覧）を用意する。
- 公開先: GitHub Pages を想定。リポジトリ名と公開の実施は完成後にユーザーへ確認する。
- 施設固有の運用（心筋保護液の種類、昇圧薬を誰が投与するか等）: 特定施設に寄せず、国際的に一般的な表現を基本とし、差がある箇所は注記する。
